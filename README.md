# Windows 11 搜索界面仿真（PySide6）

## 项目简介
本项目基于 PySide6 实现了一个高度还原 Windows 11 搜索界面的桌面应用，支持多标签页、搜索框、常用应用、最近使用、快捷搜索等功能，界面风格现代美观，适合学习 PySide6 和桌面 UI 设计。

## 主要功能
- Windows 11 风格的搜索主界面
- 多标签页（All、Apps、Documents、Web、More）
- 搜索输入框与交互
- 常用应用快捷入口
- 最近使用与快捷搜索区域
- 响应式布局与美观样式

## 运行环境要求
- Python 3.7 及以上
- PySide6

## 安装方法
1. 安装 Python 3（推荐 3.7 及以上）
2. 安装依赖库：
   ```bash
   pip install PySide6
   ```

## 运行方法
在项目根目录下执行：
```bash
python main.py
```

## 文件结构
- `main.py`：主程序文件，包含全部界面与逻辑

## 适用场景
- 桌面 UI 设计学习
- PySide6 项目模板
- Windows 11 风格界面仿真
