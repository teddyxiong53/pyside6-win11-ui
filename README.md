# PySide6 工业面板与音频处理台界面

## 项目简介
本项目基于 PySide6 实现，包含工业设备监控操作面板（factory_test.py）和音频处理台（audio_tune2.py）两个主要界面，适用于工业自动化监控、测试台操作及音频信号处理等场景。

## 主要功能
- **工业面板（factory_test.py）**：
  - 轴承温度与状态实时显示
  - 测试台控制（电机、油泵、冷却等）
  - 关断振动、温度、速度、流量、轴向液压等监控与关断
  - 电机润滑与安全指示灯
- **音频处理台（audio_tune2.py）**：
  - 高频/低频分段动态范围压缩（DRC）
  - 分频器曲线可视化
  - 频段开关、静音、增益、阈值、包络参数调节

## 依赖环境
- Python 3.7+
- PySide6
- numpy

安装依赖：
```bash
pip install PySide6 numpy
```

## 运行方法
在终端进入项目目录，运行以下命令启动对应界面：

- 启动工业面板：
```bash
python factory_test.py
```
- 启动音频处理台：
```bash
python audio_tune2.py
```

## 主要文件说明
- `factory_test.py`：工业设备监控与操作主界面，包含温度、振动、流量等多项监控与控制功能。
- `audio_tune2.py`：音频信号处理台界面，支持分频、动态压缩、参数可视化。
- `main.py`、`main_tk.py`、`main_wx.py`：其他入口或界面测试文件。
